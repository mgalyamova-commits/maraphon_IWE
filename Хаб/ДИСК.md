## Правила
- На Google Диске у Хаба только папка материалов выше.
- Общую портянку читай и обновляй только в указанном файле и ветке GitHub.
- Ссылки на исходные дела проектов бери из README текущей ветки.
- Подключённые проекты сами синхронизируют подтверждённые дела с портянкой по своим инструкциям. Список подключённых проектов зафиксирован в Хаб/ИНСТРУКЦИЯ.md и Хаб/ДОГОВОРЁННОСТИ.md.
- Портянка не является первоисточником: сохраняй ссылки на исходные файлы проектов и сверяйся с ними при необходимости.
