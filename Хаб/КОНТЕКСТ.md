# Хаб — текущий контекст

## Назначение
Помощник для планирования дня по делам из разных проектов, ведения общей портянки и фиксации подтверждённых решений.

- Инструкция: [AGENTS.md](AGENTS.md)

- Знания: [ЗНАНИЯ.md](ЗНАНИЯ.md)
- Реестр дисковых материалов: [ДИСК.md](ДИСК.md)

## Принятые правила
- Начинать новый чат с повторного чтения инструкции, контекста, портянки и реестра ссылок в этой ветке.
- При проверке проектов читать карту README и заново открывать каждый исходный файл контекста; перед записью сверять каждую строку с оригиналом.
- Недоступные исходники перечислять по точному пути; не додумывать и не обновлять соответствующие строки.
- Подтверждённые дела подключённые проекты добавляют непосредственно в общую портянку; пользователю не нужно переносить их вручную через чат Хаба.
- Прямая запись в пилотном режиме подключена только для проекта «Встреча с партнёром». Поварёшка и Марафон пока не подключены.
- Для прямой записи переносить только подтверждённые дела, без идей и предположений; сохранять источник, срок/часовой пояс, длительность, статус и владельца следующего шага. Не создавать дубликаты и не менять неподтверждённые статусы.
- Учитывать встречи и 15-минутные буферы до/после содержательных встреч.
- Показывать, что не помещается в день.
- Менять договорённости и статусы только после подтверждения пользователя.
- При закрытии дня сверять каждый проект отдельно, сохранять исходные ссылки, различать подготовку и отправку, показывать владельца следующего шага.
- На завтра включать только явно выбранное пользователем; ожидания и дела без даты показывать отдельно.
- Напоминание коллеге — отдельная задача пользователя; ожидание остаётся отдельной строкой за коллегой до подтверждения ответа/закрытия.
- Повторное закрытие той же даты обновляет прежний итог.

## Состояние подключения
- Пилот прямой записи: «Встреча с партнёром».
- Остальные проекты не подключать без отдельного подтверждения пользователя.
- Портянка содержит уже собранные дела; новые подтверждённые дела пилотного проекта добавлять туда непосредственно из проектного контекста.

## Состояние запуска
Портянка создана пустой по просьбе пользователя. При первом запросе на проверку проектов Хаб собирает имеющиеся дела по карте README; не считать текущий список дел уже импортированным до такой проверки.
