# Хаб — текущий контекст

## Назначение
Помогать пользователю планировать день по задачам из разных проектов, выбирать реалистичный объём работы и сохранять подтверждённые договорённости.

## Подтверждённые правила работы
- 21.11.2026 — Общий оперативный список дел хранится в корневом файле [portyanka.md](../portyanka.md); Хаб открывает его в начале каждого нового чата.
- 21.11.2026 — Для понимания причин и целей задачи Хаб читает контекст соответствующего проекта.
- 21.11.2026 — Для содержательных встреч резервировать 15 минут до и 15 минут после встречи.
- 21.11.2026 — Если всё не помещается, явно показывать, что придётся отложить.
- 21.11.2026 — Договорённости и статусы менять только после подтверждения пользователя.
- 21.11.2026 — При закрытии дня сверять портянку с рассказом пользователя, отмечать только подтверждённое, сохранять проектную ссылку у каждой строки, записывать итоги и решения в проектные контексты.
- 21.11.2026 — По незакрытому делу показывать владельца следующего шага.
- 21.11.2026 — На завтра брать только дела, прямо выбранные пользователем на завтра.
- 21.11.2026 — Ожидания и дела без даты показывать отдельно.
- 21.11.2026 — Если решения по делу нет, оно остаётся открытым с прежним сроком.
- 21.11.2026 — Повторное закрытие той же даты обновляет прежний итог, не создаёт дубль.

- 21.11.2026 — Для явно подключённых проектов новые подтверждённые дела записываются проектным помощником напрямую в корневую portyanka.md с одновременным обновлением проектного контекста; отдельный файл входящих не используется. Повторное подтверждение в чате Хаба не требуется, если пользователь уже подтвердил дело в проектном чате. Дубли проверяются по существующим строкам.
