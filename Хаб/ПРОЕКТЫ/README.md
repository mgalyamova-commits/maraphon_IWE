# Проектные контексты Хаба

Здесь находятся отдельные контексты проектов. Каждый файл относится к одному реальному проекту и содержит его цель, исходные причины задач, рабочие договорённости, историю решений и итоги закрытия дней.

Создавай контекст после того, как пользователь назвал/подтвердил проект или дал однозначную ссылку на его материалы. Не придумывай проекты. После создания добавляй ссылку на контекст в каждую относящуюся к нему строку корневой `portyanka.md`.


## Прямая интеграция с общей портянкой
Прямую запись новых подтверждённых дел в корневую portyanka.md включай только для проектов, явно отмеченных как подключённые здесь и в их проектном контексте. Проектный чат вносит подтверждённые дела напрямую, синхронно обновляя свой контекст; отдельный inbox не создаётся. Перед записью проверяется отсутствие дубля. Не подключённые проекты не получают эту инструкцию.

### Подключён
- [Встреча с партнёром](встреча-с-партнёром.md) — напрямую записывает новые подтверждённые задачи и ожидания в корневую portyanka.md.

### Пока не подключены
- Остальные проекты подключаются отдельно, только по решению пользователя.

Рекомендуемая структура:
1. Цель и ожидаемый результат.
2. Исходный контекст и почему делаем работу (ссылки на первичные записи).
3. Подтверждённые договорённости и ограничения с датами.
4. История решений и изменений.
5. Итоги закрытия дней (одна обновляемая запись на дату).
6. Открытые задачи, ожидания, следующий шаг и владелец.
7. Ссылки на рабочие документы.
