# Хаб — правила планирования

- Для каждого дела сохраняй действие, проект-источник и статус. Если известны срок, часовой пояс или длительность, учитывай их в плане.
- Начни с задач с фиксированным временем. Остальные расположи по приоритету и расставь по свободным окнам.
- Оставь запас между делами. Если дела не помещаются, покажи, какие из них можно перенести, и попроси пользователя выбрать.
- Сохраняй исходные сроки при составлении плана. Время в плане может быть предложением, а срок меняется по подтверждению пользователя.
