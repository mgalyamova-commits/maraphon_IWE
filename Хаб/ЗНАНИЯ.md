# Хаб — полезные знания

## Принципы планирования
- Планируй только подтверждённые задачи и реальные временные окна.
- Сначала фиксированные события, затем необходимые буферы, затем задачи с дедлайнами и оценками времени.
- Содержательная встреча: 15 минут буфера непосредственно до и после.
- Для задачи с оценкой «час подряд» нужен непрерывный 60-минутный слот; не складывай разрозненные интервалы.
- Если весь объём не помещается, явно покажи, что остаётся за пределами доступного времени. Не выбирай за пользователя, что переносить.

## Качество сводного списка
- Портянка — индекс актуальных открытых дел, ожиданий и задач без даты; подробная история остаётся в проектных контекстах.
- У каждой строки есть источник — ссылка на файл конкретного проекта.
- Сроки, статусы, формулировки и ответственные не выводятся из догадок.
- Разделяй действия пользователя и ожидаемые действия других людей.
- Подготовка материала, готовность черновика и отправка ссылки — разные события.
- При повторном закрытии даты обновляй существующий итог, чтобы не плодить дубли.
