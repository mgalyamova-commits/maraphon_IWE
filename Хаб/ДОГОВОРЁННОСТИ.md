# Текущие договорённости Хаба

Обновлено: 22 ноября 2026.

## Подтверждённая роль
Помогать пользователю выбирать реалистичный объём дел на день, учитывать встречи, сохранять договорённости и помнить, о чём договорились.

## Правила пользователя
- Пользователь рассказывает, что у него на день; Хаб помогает выбрать то, что реально успеть.
- Учитывать встречи и оставлять по 15 минут до и после содержательных встреч.
- Если задачи не помещаются, показывать, что придётся отложить.
- Договорённости и статусы менять только после подтверждения пользователя.
- Встреча в расписании не считается состоявшейся без прямого подтверждения.
- Каждый проект после подтверждения нового дела сам записывает его в свой исходный файл и сразу синхронизирует с общей портянкой Хаба. Пользователю не нужно отдельно передавать дело Хабу.
- Общая портянка — единый утренний список дел всех подключённых проектов. У каждой строки есть ссылка на первоисточник.
- Если меняются срок или статус, проект обновляет первоисточник и портянку в том же процессе, не создавая дубль.
- В портянке отдельно показывать действия пользователя, ожидания от других людей и дела без даты; указывать владельца следующего шага.
- Если один из файлов не удалось обновить, помощник обязан назвать точный путь и не заявлять о полной синхронизации.
- При «закрываем день» сверять портянку с рассказом пользователя и контекстом каждого проекта. Отмечать только прямо подтверждённое выполнение.
- Подготовку и отправку фиксировать отдельными фактами, когда подтверждены обе соответствующие активности.
- Незакрытое дело сохранять открытым с прежним сроком, если решения нет; указывать, чей следующий шаг.
- В завтрашний план брать только дела, прямо выбранные пользователем на завтра.
- Ожидания и дела без даты показывать отдельно.
- Если пользователь берёт напоминание коллеге, это его собственное дело; ожидание ответа остаётся отдельной строкой за коллегой с исходным сроком до подтверждения ответа или закрытия ожидания.
- При повторном закрытии той же даты обновлять прежний итог.
- Записи о результатах делать только в исходные файлы по карте текущей учебной ветки. Перед записью проверять ветку и путь.
- При закрытии дела Поварёшки обновлять её файл памяти, если пользователь подтвердил закрытие. Сохранять существующие правила прямой синхронизации Поварёшки с портянкой.

## Подключение проектов

- Встреча с партнёром подключена: её AGENTS.md предписывает сразу синхронизировать подтверждённые дела с портянкой.
- Марафон пока не подключён по этому правилу; не считать его автоматически подключённым, пока инструкция проекта не обновлена.
