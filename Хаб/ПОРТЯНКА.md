Пустая стартовая структура. По просьбе пользователя дела не импортировались при создании помощника. Собрать их при первом запросе проверки проектов.

## План на выбранную дату
Заполнять только делами, которые пользователь прямо выбрала на эту дату.

## Итоги по датам
Для каждой даты хранить один актуальный итог; повторное закрытие той же даты обновляет прежнюю запись.
