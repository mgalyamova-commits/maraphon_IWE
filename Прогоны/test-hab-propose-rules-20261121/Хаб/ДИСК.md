# Хаб — реестр рабочих документов

## Рабочая папка
[Хаб — рабочие материалы](https://drive.google.com/drive/folders/1iUZfLZD-_Gb_r757OPg3Mo3-6B0FPAtQ)

## Назначение
В этой папке размещаются рабочие документы Хаба и материалы, на которые ссылаются проектные контексты. Не перемещай и не редактируй документы других помощников.

## Источники
- Общий список задач: [portyanka.md в GitHub](../portyanka.md).
- Правила Хаба: [AGENTS.md](AGENTS.md).
- Текущие договорённости: [КОНТЕКСТ.md](КОНТЕКСТ.md).
- Полезные знания: [ЗНАНИЯ.md](ЗНАНИЯ.md).

## Проектные контексты
Для каждого подтверждённого проекта веди отдельный файл в `Хаб/ПРОЕКТЫ/` (например, `Хаб/ПРОЕКТЫ/название-проекта.md`). В нём храни цель, исходный контекст, историю решений, итоги закрытия дней, открытые вопросы и ссылки на первичные документы. В портянке у каждой задачи должна быть ссылка на такой файл. Пока проекты не идентифицированы, не создавай фиктивные проектные записи.
