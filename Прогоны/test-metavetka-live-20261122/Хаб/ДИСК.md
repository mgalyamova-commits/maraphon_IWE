# Хаб — реестр документов

- [Общая папка показа](https://drive.google.com/drive/folders/1FEzRPqrtH4ViU5W4B0JDKWIjP5jnfOZc).
- [Рабочая папка Хаба](https://drive.google.com/drive/folders/1CUkEqbnrr_5vQ1LKHj7D5LTT6RZJ5KaW) находится непосредственно в общей папке показа, рядом с папкой Поварёшки.
- [Хаб — Портянка (тестовая копия)](https://docs.google.com/document/d/1GXkkqIcKiaFGX1_OdNE7MGVXHa47zmdcVWi7lD-4oJs/edit) — единственная портянка для этого тестового прогона. Перед записью проверь доступность и актуальное содержание; при недоступности не заменяй её рабочей портянкой. На момент настройки ссылка вернула отказ в доступе (403), доступ необходимо проверить отдельно.
- **Запрет тестового прогона:** другие документы Google Диска, включая документы по ссылкам на общую и рабочую папки, изменять нельзя. Ссылки на папки выше приведены только для ориентира.
