# Рабочие документы Поварёшки

[Рабочая папка марафона на Google Drive](https://drive.google.com/drive/folders/1L9XBwc7ATU-SmQ87dqaPZQY2WVvkESQx).

Для реальных домашних запросов открывай из этой папки существующие документы по точному имени.

| Документ | Назначение |
| --- | --- |
| Поварёшка — Текущий контекст | Домашние привычки и договорённости |
| Поварёшка — Список продуктов | Наличие продуктов, количество и дата проверки |
| Поварёшка — Кулинарные знания | Исходный справочник приёмов |
| Поварёшка — Правила | Исходная версия инструкции до перехода на GitHub |

Актуальная учебная роль живёт в [GitHub](AGENTS.md), учебные дела — в [учебной памяти](ПАМЯТЬ.md) и [портянке Хаба](../Хаб/ПОРТЯНКА.md). Реальный домашний контекст ведётся в существующем документе на Диске. Папки `ТЕСТ запуска` и их вложенные документы относятся к репетициям.
