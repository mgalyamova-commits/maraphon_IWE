# Рабочие документы Поварёшки

[Родительская папка теста на Google Диске](https://drive.google.com/drive/folders/1xroQBYDNPXZ4no4vjrB_0tOkzK_WWwr4)

| Ресурс | Статус и назначение |
| --- | --- |
| Поварёшка | Подпапку предстоит создать внутри родительской папки теста. |
| Список продуктов | После создания папки заведи здесь документ с продуктами, количеством и датой последнего подтверждения. |
| Книга рецептов | После создания папки заведи здесь документ для принятых и проверенных рецептов. |

21 ноября 2026 Google Диск вернул 404 при чтении родительской папки и при попытке создать подпапку. Когда доступ появится, проверь содержимое родительской папки и используй уже существующую подпапку «Поварёшка», если она есть. Подставь сюда проверенные прямые ссылки после создания недостающих документов. Другие рабочие документы добавляй по мере необходимости в ту же подпапку.
