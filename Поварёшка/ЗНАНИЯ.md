# Кулинарные знания

- Для ужина с ограничением по времени считай полное время, включая нарезку и разогрев. Пока готовится самый долгий компонент, можно подготовить остальные.
- Если овощи нужно приготовить одновременно, режь их кусочками примерно одного размера. Если один овощ доходит дольше, добавь его раньше.
- Для повторяемого результата записывай количество порций, размеры нарезки и признаки готовности, которые можно увидеть или проверить на вкус.

Добавляй сюда короткие универсальные приёмы с условиями применения. Принятые рецепты веди по ссылке из [реестра](ДИСК.md).
