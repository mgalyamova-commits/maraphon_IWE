# Поварёшка — учебная память после первого дня

## Договорённости для упражнения

- В учебном ужине грибы исключены.
- Предлагай блюда из подтверждённых продуктов. Если для варианта нужен продукт, которого не было во вводных, сначала спроси, есть ли он.

## Открытые учебные дела

- **Открытое дело:** 22 ноября 2026 года до 09:30 по Новосибирску (UTC+7) проверить, есть ли дома рис на ужин. Плановая длительность — 5 минут. Статус: результат проверки не сообщён, дело остаётся открытым; при фиксации записи указанный срок уже прошёл.
- **Открытое дело:** проверить, остался ли дома чай. Дата и срок не назначены. Статус: ожидает проверки; результат не сообщён. Следующий шаг: проверить, остался ли чай дома.

## Последний результат и точка продолжения

Первый запуск Поварёшки завершён. Перед следующим запросом открой [инструкцию](AGENTS.md) и [список продуктов по реестру](ДИСК.md). Применяй данные учебного запроса и фиксируй подтверждённый результат здесь.
