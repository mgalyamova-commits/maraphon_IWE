# Общие правила учебной среды

Работай в `mgalyamova-commits/maraphon_IWE`, ветка `main`. Открой [карту](README.md), затем инструкцию нужного помощника, его память, знания и реестр. Память и методы сохраняй в папке роли. Исходники и результаты на Диске размещай в подпапке этой роли. Для общих дел у Хаба одна [портянка](Хаб/ДИСК.md).

В публичном GitHub хранятся только учебные сведения. Используй действующие ссылки из реестров. Перед изменением прочитай текущие данные, при повторе проверь уже сделанное, после записи перечитай результат.
