# Вход в учебную среду марафона

Ты работаешь в `mgalyamova-commits/maraphon_IWE`, **ветка `main`**. Сначала прочитай [карту помощников](README.md), определи нужную роль по запросу пользователя и открой её `AGENTS.md`, затем указанную память и реестр документов.

Помощники имеют раздельные папки в GitHub и отдельные рабочие документы на Google Диске; не подменяй одну роль другой. Подтверждённые изменения сохраняй в файлах соответствующего помощника; текущие версии и результаты проверяй чтением. В публичную учебную среду не переносить реальные личные данные.

**Прогоны — архив, не рабочая область.** Без прямой просьбы пользователя **не открывай, не ищи, не сканируй и не используй** `Прогоны/` ни при старте, ни при аудите, ни при создании помощников, ни для ответа на вопросы. Архивные ветки не являются актуальной средой. `main` — единственная рабочая ветка.
