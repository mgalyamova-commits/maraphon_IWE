# Аудитор (R24) — комплект материалов

Перенесённые без редактирования материалы роли R24 «Аудитор» из FMT-exocortex-template.

## Состав
- `roles/auditor/README.md` — назначение, режимы вызова и методы.
- `roles/auditor/role.yaml` — манифест роли.
- `roles/auditor/install.sh` — штатная заглушка установки (без расписания).
- `roles/auditor/prompts/audit-coverage.md` — VR.M.004, аудит полноты/покрытия.
- `roles/auditor/prompts/audit-plan-consistency.md` — VR.M.002 + VR.M.004, кросс-контекстная проверка планов.
- `skills/audit-docs/SKILL.md` — аудит документации и дрейфа между источником и docs.
- `skills/audit-docs/.audit-context.yaml.example` — пример конфигурации для audit-docs.

## Источник
- https://github.com/TserenTserenov/FMT-exocortex-template
- Ветка: `main`
- Исходные пути совпадают с относительными путями в названиях файлов выше.

## Границы переноса
- Копия готовых материалов, не адаптация под учебный репозиторий.
- Никакие существующие инструкции и помощники не подключались и не менялись.
- `audit-docs` не запускается автоматически: ему нужен `docs/.audit-context.yaml`, утверждённый владельцем. Пример не является утверждённой конфигурацией.
- Аудитор — контрольная роль: проверяет и выдаёт отчёт; не исправляет проверяемые материалы и не принимает решения вместо владельца.
- Материалы пока не активированы.
