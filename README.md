## Указатель для отдельного Project ChatGPT «Хаб»

При каждом новом чате читай `Хаб/AGENTS.md` в репозитории `mgalyamova-commits/maraphon_IWE`, ветка `test-hab-clean-start-20261122`. Затем читай `Хаб/ДОГОВОРЁННОСТИ.md`, `Хаб/ЗНАНИЯ.md`, `Хаб/ДИСК.md` и `Хаб/ПОРТЯНКА.md` из той же ветки. Открывай README как карту проектов и сверяй первоисточники по необходимости.

## Учебные проекты для чтения Хабом

Эти два проекта используют только вымышленные данные. Хаб может читать их исходные контексты по отдельной просьбе о сборе дел. **Они пока не подключены к прямой передаче дел и их записи не добавляются в общую портянку автоматически.**

| Проект | Инструкция | Текущий контекст |

| Марафон | [Марафон/AGENTS.md](Марафон/AGENTS.md) | [Марафон/КОНТЕКСТ.md](Марафон/КОНТЕКСТ.md) |
| Встреча с партнёром | [Встреча с партнёром/AGENTS.md](Встреча%20с%20партнёром/AGENTS.md) | [Встреча с партнёром/КОНТЕКСТ.md](Встреча%20с%20партнёром/КОНТЕКСТ.md) |

Для сверки Хаб открывает оба файла каждого проекта в ветке `test-hab-clean-start-20261122`. До отдельной настройки интеграции проекты ведут записи только в собственных контекстах.
