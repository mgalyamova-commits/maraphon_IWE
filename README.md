## Как запускать

Для каждого ChatGPT Project задай короткий указатель: «В начале каждого чата открой <имя помощника>/AGENTS.md в `mgalyamova-commits/maraphon_IWE`, ветка `main`, и работай по нему». Дальше помощник самостоятельно открывает память и нужные документы. При замене учебной ветки нужно обновить и указатели в настройках Projects.

Одна согласованная портянка — по ссылке в `Хаб/ДИСК.md`. Старые портянки из репетиций **не являются рабочим источником**.

## Архив репетиций — закрытая область

В папке [Прогоны/](Прогоны/README.md) сохранены исторические снимки **всех прежних репетиционных веток**, включая прежний `main`. Они нужны только для восстановления и специального сравнения.

**Запрет по умолчанию:** ни один помощник не должен открывать, искать, анализировать, переписывать, использовать для ответа или выбирать рабочую ветку из `Прогоны/`, пока пользователь прямо не попросил работать с архивом. Аудит Метаветки также работает только с текущими файлами; архив не сканировать. Не цитировать оттуда старые инструкции как актуальные.

Ничего из архива не переносить в рабочий комплект молча. Текущая рабочая ветка — только `main`.
