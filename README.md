[Инструкция](Поварёшка/AGENTS.md) · [Учебная память](Поварёшка/ПАМЯТЬ.md) · [Кулинарные знания](Поварёшка/ЗНАНИЯ.md) · [Документы на Диске](Поварёшка/ДИСК.md) | Подключена: подтверждённые учебные кухонные дела синхронизируются напрямую |

## Указатель для отдельного Project ChatGPT «Поварёшка»

При каждом новом чате читай `Поварёшка/AGENTS.md` в репозитории `mgalyamova-commits/maraphon_IWE`, ветка `test-hab-clean-start-20261122`. Используй память и документы, указанные в этой ветке. Подтверждённые учебные дела синхронизируй с `Хаб/ПОРТЯНКА.md` по инструкции проекта.

## Указатель для отдельного Project ChatGPT «Хаб»

При каждом новом чате читай `Хаб/AGENTS.md` в репозитории `mgalyamova-commits/maraphon_IWE`, ветка `test-hab-clean-start-20261122`. Затем читай `Хаб/ДОГОВОРЁННОСТИ.md`, `Хаб/ЗНАНИЯ.md`, `Хаб/ДИСК.md` и `Хаб/ПОРТЯНКА.md` из той же ветки. Открывай README как карту проектов и сверяй первоисточники по необходимости.

## Указатель для отдельного Project ChatGPT «Встреча с партнёром»

При каждом новом чате читай `Встреча с партнёром/AGENTS.md` и `Встреча с партнёром/КОНТЕКСТ.md` в репозитории `mgalyamova-commits/maraphon_IWE`, ветка `test-hab-clean-start-20261122`. Подтверждённые дела и изменения синхронизируй с `Хаб/ПОРТЯНКА.md` по инструкции проекта: сначала сохраняй подробности у себя, затем обновляй общую портянку и проверяй чтением оба файла.

## Учебный проект «Марафон»

Хаб может читать этот проект по отдельной просьбе о сборе дел. Проект хранит задачи и результаты только в собственном контексте; прямой передачи в общую портянку пока нет.
