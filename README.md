# Марафон IWE — карта помощников

Два самостоятельных помощника работают в этой учебной ветке.

| Помощник | Роль и рабочие материалы |
| --- | --- |
| Поварёшка | Домашние ужины, подтверждённые продукты и рецепты. [Инструкция](Поварёшка/AGENTS.md) · [Учебная память](Поварёшка/ПАМЯТЬ.md) · [Кулинарные знания](Поварёшка/ЗНАНИЯ.md) · [Документы на Диске](Поварёшка/ДИСК.md) |
| Хаб | Планирование дня, открытые дела, ожидания и итоги. [Инструкция](Хаб/AGENTS.md) · [Договорённости](Хаб/ДОГОВОРЁННОСТИ.md) · [Полезные знания](Хаб/ЗНАНИЯ.md) · [Рабочие документы](Хаб/ДИСК.md) · [Общая портянка](Хаб/ПОРТЯНКА.md) |

[Общая папка показа на Диске](https://drive.google.com/drive/folders/1GRdyRLZviwwYr9wgf_X-WtwiD57VaCuW).

## Указатель для отдельного Project ChatGPT «Поварёшка»

При каждом новом чате читай `Поварёшка/AGENTS.md` в репозитории `mgalyamova-commits/maraphon_IWE`, ветка `test-hab-clean-start-20261122`. Используй память и документы, указанные в этой ветке.

## Указатель для отдельного Project ChatGPT «Хаб»

При каждом новом чате читай `Хаб/AGENTS.md` в репозитории `mgalyamova-commits/maraphon_IWE`, ветка `test-hab-clean-start-20261122`. Затем читай `Хаб/ДОГОВОРЁННОСТИ.md`, `Хаб/ЗНАНИЯ.md`, `Хаб/ДИСК.md` и `Хаб/ПОРТЯНКА.md` из той же ветки. Открывай README как карту проектов и сверяй первоисточники по необходимости.
